# 🔮 마법의 수정구슬 — 마음을 읽는 마술

**두 자리 수를 이용한 숫자 마술 게임!** 마음속으로 계산한 숫자 옆의 기호를 기억한 뒤 수정구슬을 누르면, 수정구슬이 그 기호를 맞힙니다.

- **분류:** 교육용 웹게임 / 수학 마술
- **관련 교과:** 수학 (자릿값, 뺄셈, 9의 배수)
- **기술:** HTML, CSS, JavaScript
- **실행 환경:** 웹브라우저 (PC 화면 권장)
- **특징:** 설치·회원가입 불필요, 새 게임마다 기호 변경, 수정구슬 클릭 시 효과음 재생

## 🎮 게임 방법

1. 마음속으로 **두 자리 숫자**를 하나 생각합니다.
2. 그 숫자의 **십의 자리와 일의 자리 숫자를 더합니다.**
3. 처음 생각한 숫자에서 2번의 결과를 뺍니다.
4. 화면 오른쪽 표에서 **계산한 숫자 옆의 기호**를 찾아 기억합니다.
5. **수정구슬을 클릭**하면 기억한 기호가 나타납니다!
6. **「🌟 새로운 마술 하기 🌟」** 버튼을 누르면 새로운 기호로 다시 시작할 수 있습니다.

> 예: **53 → 5 + 3 = 8 → 53 - 8 = 45**. 표에서 **45** 옆의 기호를 기억하면 됩니다.

## 📁 파일 구성

```text
mind-reader/
├── index.html        # 게임 본체 (기존 flash mind reader.html의 이름 변경 권장)
├── magic_sound.mp3   # 수정구슬 클릭 시 재생되는 효과음
└── README.md         # 프로젝트 설명
```

**중요:** `index.html`과 `magic_sound.mp3`를 **같은 폴더**에 올려야 소리가 정상적으로 재생됩니다. 파일 이름의 **대소문자**도 정확히 일치해야 합니다.

## 🚀 실행 방법

### 내 컴퓨터에서

`index.html` 파일을 브라우저로 열면 됩니다. 효과음을 사용하려면 `magic_sound.mp3`가 같은 폴더에 있어야 합니다.

### GitHub Pages에 공개하기

1. GitHub에 새 저장소를 만듭니다. (예: `mind-reader`)
2. 기존 `flash mind reader.html`의 이름을 **`index.html`**로 변경합니다.
3. `index.html`, `magic_sound.mp3`, `README.md`를 저장소의 **최상위 폴더**에 업로드합니다.
4. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch를 **`main`**, 폴더를 **`/(root)`**로 지정하고 **Save**를 누릅니다.
6. 배포가 완료되면 다음 형식의 주소에서 실행할 수 있습니다.

   `https://사용자명.github.io/mind-reader/`

※ 주소의 `mind-reader`는 실제 저장소 이름으로 바꿔야 합니다.

## 🧠 마술의 원리

두 자리 수를 `10a + b`라고 하면, 십의 자리와 일의 자리의 합은 `a + b`입니다.

```text
(10a + b) - (a + b) = 9a
```

따라서 계산 결과는 언제나 **9의 배수(9, 18, 27, …, 81)**입니다. 게임은 이 숫자들에 **같은 기호**를 표시하기 때문에 수정구슬이 마음속 기호를 맞히는 것처럼 보입니다. 게임을 새로 시작할 때마다 기호 배치가 다시 만들어집니다.

## 🛠️ 참고 사항

- 게임은 별도의 서버나 데이터베이스 없이 동작합니다.
- 효과음은 `magic_sound.mp3` 파일에서 불러오며, **수정구슬 클릭 시** 재생됩니다.
- 효과음 파일이 없거나 재생이 차단되어도 게임 화면과 기호 공개 기능은 동작할 수 있습니다.
- 현재 화면 구성은 **PC처럼 가로 공간이 넓은 화면**에 더 적합합니다. 좁은 스마트폰 화면에서는 일부 내용이 불편하게 보일 수 있습니다.
- 글꼴은 Google Fonts의 **Jua**를 사용하므로 네트워크 환경에 따라 기본 글꼴로 표시될 수 있습니다.
